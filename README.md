# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

This assignment practices Python functions, parameters, return values, and default parameters.

* `welcome.py` - Contains the `welcome()` function, which creates a greeting for different names.
* `toolbox.py` - Contains the `double()`, `is_pass()`, and `greet()` functions.

The `greet()` function was the hardest to write because it uses an optional parameter with a default value. I had to understand how Python uses `"Hello"` when no greeting is provided and uses the supplied greeting when one is given.
